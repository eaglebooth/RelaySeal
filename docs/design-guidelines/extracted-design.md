## Visual direction

The logo combines two people, a directional transfer arrow and a verified shield.
The UI translates that into a **shift handover dossier**, not a crypto dashboard:
wide paper sheets, punched timeline markers, blue verification stamps, horizontal
transfer rails and compact operations typography. It intentionally avoids the
dark terminal/control-room language used by earlier workspace projects.

## Interaction rules

- A horizontal rail shows authority moving from outgoing to incoming operator.
- Semantic verdicts use both text and iconography, never color alone.
- Forms are grouped as numbered dossier sections with generous whitespace.
- Transaction progress remains visible until finality and canonical readback.
- Mobile layout becomes a vertical case folder without horizontal overflow.
